# OK 品牌候选

三套只替换主色和状态色，布局与中性色仍用 `design/tokens.css`。**待用户选定。**

对比度是白字 `#FFFFFF` 相对该按钮底色，深色主题和浅色主题使用同一组按钮色，所以两套主题的比值相同。ΔE 为 CIE76。色相是 CIELAB 色相角之差（0–180°）。

## A · 蓝

沿用现有规范的蓝 #2563EB，运行绿与主色色相相差约 146°，按钮、链接和运行状态各看各的。

| primary | `#2563EB` | `#2563EB` |
| hover | `#1D4ED8` | `#1D4ED8` |
| pressed | `#1E40AF` | `#1E40AF` |
