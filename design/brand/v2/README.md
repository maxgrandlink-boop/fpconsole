# PANDA Browser 品牌候选 v2

产品名是 PANDA Browser。侧栏写 PANDA，下面一行「指纹浏览器」。三套渐变各一只大熊猫，外加一只红熊猫供对比。**待用户选定。** 选定前不改 `design/tokens.css` 和 `design/naive-theme.ts`。

上一轮 `design/brand/a|b|c` 和 `brand-options.png` 已删除。

对比度用 `node design/brand/v2/contrast.mjs` 复算（WCAG 相对亮度，渐变按钮取两端里更差的一端；色差是 CIE76 ΔE，色相是 CIELAB 色相角差）。按钮字色在深色主题和浅色主题是同一套，所以两套主题的按钮对比度相同。门槛是 4.5:1。

Logo：同一只熊猫。黑白五官（圆脸、黑耳朵、黑眼圈、小鼻子），该套渐变做圆形底板和脸颊。大图和 256 应用图标加了眼白、高光。28px 去掉眼白和脸颊，只留能认出来的轮廓。应用图标是圆角方底板加顶部高光，不是把 256 图标缩小当 28px。
