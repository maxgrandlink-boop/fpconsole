# fpconsole 设计规范

桌面端浏览器实例（环境）管理台。深色为默认外观，信息密度按运营批量操作来排。本文只描述界面与交互，业务规则全部来自当前 `main` 上的原型：`web/mock-notes.md`、`web/app.js`、`web/mock.js`、`web/index.html`。没有写进旧代码的行为，放在文末「待确认」，效果图里若出现，只作为把交互画清楚的界面草案。

实现目标栈是 electron-vite + Vue 3 + TypeScript + Naive UI。令牌映射在 `design/naive-theme.ts`，已按 naive-ui 2.45 的 `GlobalThemeOverrides` 通过类型检查。效果图使用同一套变量：`design/tokens.css`。

## 1. 现有功能清单

原型是纯前端 MOCK：内存数据，刷新重置；路径设置写入 `localStorage`（键 `fpconsole-path-settings`）。右上角 MOCK 徽标点开后 toast：「当前为纯 UI 原型（MOCK 模式）：所有数据为内存 mock，刷新页面即重置」。路由 `#/env`（默认）、`#/proxy`；`#/` 与未知 hash 回落到环境管理。

### 1.2 新建与锁定

- 旧原型里 slot 手填、必填、最长 64。空则「请填写 slot 名」；重复（大小写不敏感）则 409，「该 slot 已存在，请换一个名字」。新控制台改为按地区前缀自动续号，见 6.4。并发冲突仍用这句 409。
- 提交中按钮文案「生成中…」并禁用。成功 toast：「环境「{slot}」已生成并锁定」，新行立刻出现：已锁定、used=0、代理未检测、类型静态、smartproxy 随机城市 URI、分组默认分组、不置顶、不星标。
- 语言 = 基于 IP 生成时，记录值为 `en-US`；自定义则用输入，空则回落 `en-US`。
- 时区 = 基于 IP 生成时，记录值为 `America/Los_Angeles`；自定义用下拉值。
- 分辨率 = 随机时，从 `1366×768`、`1440×900`、`1536×864`、`1600×900`、`1920×1080` 里抽一个；快捷选择或自定义都用同一个下拉的值，默认 `1920×1080`。
- 新环境的 Chrome 主版本在 150–156 间随机，不是表单项。
- 警示原文：「生成后永久固定，不可重新生成。指纹一旦生成立即锁定，与该槽位永久绑定；本界面不提供任何「重新生成」入口。」
- 查看（行内编辑图标）打开同一面板的只读态：控件 disabled，黄条「人设已锁定，仅查看」，底部只有「关闭」。没有编辑保存。

新控制台不把这些项做成员工表单。点「创建并启动」时，内部规则为每个新环境单独随机生成一套指纹并立刻锁定。下表是旧原型的默认值，用来说明生成器可以产出的种类。

### 1.3 列表行为

- 搜索即时过滤，匹配 slot、name、时区、分辨率、UA、IP、地区、分组，大小写不敏感。无结果：「没有符合关键词的环境」。全空：「还没有环境，点击左侧「＋ 新建环境」生成第一个」。
- 排序：序号、创建时间，再次点击反向。置顶行永远在最前。
- 勾选后底部条：「已选 N 项｜批量启动｜批量停止｜取消选择」。批量启动跳过已运行项，toast：「批量启动完成：启动 {n} 个，跳过 {k} 个（已在运行）」。批量停止：「批量停止完成：停止 {n} 个」。失败分别是「批量启动失败：…」「批量停止失败：…」。
- 行启动成功：「已启动（PID {pid}）」，pid 从 12040 递增；used_count +1，累计启动 +1；运行行绿底、左侧绿边、状态灯、按钮变为停止。已在运行时再点「打开」：把该环境的窗口带到前面，不再提示「该环境已在运行」。创建已成功但启动失败：环境保留，该行状态为「异常」，操作里有「重试」。其他失败仍是「启动失败：」+ message。停止成功：「已停止」；失败：「停止失败：」+ message。
- 重新检测约 1.8–2.7 秒，行内骨架，结果在三条判定间轮换（见代理）。失败：「重新检测失败：」+ message。
- 星标即时切换。失败：「操作失败：」+ message。
- 更多菜单：导出配置、删除。导出下载 `{slot}.fpconsole.json`，成功「配置已开始下载」，失败「下载配置失败：…」。删除先 `confirm`：「确定删除「{slot}」？该操作不可恢复（仅 used_count = 0 可删除）。」used>0：409，「该环境已被使用，不可删除」。成功：「已删除「{slot}」」。
- 启动命令弹窗：展示拼装结果；proxy_uri 可改，改完立刻重拼；「示例」填入 smartproxy URI；「复制」成功「已复制到剪贴板」，失败「复制失败，请手动选择复制」。拼装规则以 `web/mock.js` 的 `assembleCommand` 为唯一权威，本规范不重复参数表。含空格的值加英文双引号。
- 分组管理、批量导入、标签管理、筛选、全部分组、通知铃铛：toast「原型演示：该功能未接入」。刷新：重拉列表并 toast「已刷新」。

### 1.4 代理校验

- 输入 `http://user:pass@host:port`。空提交：「请先填写 proxy_uri」。
- 「示例」填入 `http://client-demo_area-us_city-{losangeles|newyork|chicago}_life-120_session-{10位}:demo-pass@proxy.example.com:9000`。
- 验证过程文案循环：「正在检测代理出口质量」，步骤为建立隧道、请求 ipinfo、解析 org/ASN/地理位置、匹配合格规则（美国消费宽带）。
- 轮换结果，与行内重测共用序号：
  1. 76.89.201.14，US，Charter Communications，合格，「美国消费宽带（Charter 家宽段）」，地区显示美国-洛杉矶
  2. 128.199.85.7，SG，Datacamp Limited，不合格，「机房/Hosting 出口，且非美国（新加坡）」，地区显示新加坡
  3. 12.119.84.203，US，AT&T Enterprises，不合格，「AT&T Enterprises 商务线，非消费宽带」，地区显示美国-达拉斯
- 合格与不合格都是检测完成。连接没建立时原型走「验证失败：」+ message，不产生判定徽章。
- 历史最近 20 条。URI 只显示 host:port。空：「暂无检测记录」。加载失败：「历史记录加载失败：」+ message。
- 「ipinfo 直连检测」是浏览器直连 `https://ipinfo.io/json`（12 秒超时），结果标成直连出口。失败：「ipinfo.io 请求失败：」+ message。

## 2. UI/UX Pro Max 的推荐与取舍

技能版本：`ui-ux-pro-max-cli` 2.15.0，装在用户目录，检索脚本在 `~/.cursor/skills/ui-ux-pro-max/scripts/search.py`。技能本身不进仓库。

### 2.1 采用

- **风格：Dark Mode (OLED)。** 产品类型「Developer Tool / IDE」的主风格就是它，和「深色为主」一致。默认深色。
- **配色家族：Developer Tool / IDE，备注 “Code dark + run green”。** 背景 `#0F172A`，卡片 `#1B2336`，文字 `#F8FAFC`，次文字 `#94A3B8`，运行/成功 `#22C55E`，破坏性 `#EF4444`。
- **蓝色作为焦点与主操作。** 产品行的配色焦点写的是 “Dark syntax theme colors + Blue focus”。技能把 Primary 标成 `#1E293B`，那是石板色表面，铺在 `#0F172A` 上对比约 1.2:1，不能当按钮。主按钮使用同一次补检索里浅色方案的行动蓝 `#2563EB`（白字对比 5.17:1），`#1E293B` 改作抬高表面（弹窗、菜单）。
- **密度 8：间距 xs 2 / sm 4 / md 8 / lg 12 / xl 16 / 2xl 24 / 3xl 32（px）。** 运营表用这一档。
- **动效 3：Subtle。** 悬停、焦点 150ms，弹窗 200ms。落地页用的滚动揭示（GSAP scroll reveal）不用于始终可见的桌面窗体。`prefers-reduced-motion: reduce` 时去掉过渡和循环动画。
- **方差 4：均衡，不走不对称。**
- **字体气质：IBM Plex Sans + JetBrains Mono**（设计系统正文/等宽）。中文走系统字体：文泉驿微米黑、苹方、微软雅黑。效果图把拉丁字形放在 `design/fonts/`，不请求 Google Fonts。
- **表单错误：** 字段下方就地说明，并用 `aria-describedby`；提交失败时，表单顶部放可聚焦的错误摘要（`role="alert"`），条目链到字段。保留行内错误。toast 不能单独代替字段错误。
- **焦点：** 2px 环，颜色 `#93C5FD`（在卡片上对比约 8.7:1）。弹窗不把焦点完全盖住。批量操作是下拉，不另做一条挡住表格的浮条。
- **图标：** 线框 SVG，一种风格。旁边有文字时 `aria-hidden`。只有图标的按钮带 `aria-label`（刷新、路径设置、重新检测、更多、星标、通知）。状态不靠颜色单独表达，药丸里有文字。
- **Vue：** 数字用 `v-model.number`，文本用 `v-model.trim`。复杂校验可以交给 VeeValidate，规则仍以第 6 节为准。

### 2.2 未照搬的部分

- **FAQ / Documentation 落地页结构。** 主检索的 pattern 是文档站。本产品是左导航加右栏：上面快速创建，下面环境列表。产品行里对应的是 “Real-Time Monitor + Terminal”，用来支持状态、命令弹窗和等宽标识。
- **技能示例按钮的 12×24 内边距、悬停上移，以及卡片悬停上移。** 那是落地页片段，和密度 8 冲突。按钮高 32px，卡片靠边框分层，不把整张卡片做成可点击。
- **等宽字体做中文标题。** JetBrains Mono 只用于 slot、IP、URI、命令、次数、时间。界面标题用 IBM Plex Sans。
- **纯黑 `#000000` 窗口底。** 风格关键词里有深黑，但开发者工具色板的背景是 `#0F172A`。留出「底 / 侧栏 / 卡片 / 抬高」四层，窗口才分得清。侧栏再用深一档 `#0B1220`。
- **技能边框 `#475569`。** 它在 `#0F172A` 上只有约 2.4:1，不够做输入框边界（非文本对比要 3:1）。控件边框用同色阶的 `#64748B`（在卡片上约 3.3:1）。表格发丝分割线用 `#334155`，分割线不是控件的唯一边界。
- **技能阴影（0.05–0.15 透明度）。** 在深色底上几乎看不见。层级改为 0.45–0.55 透明度，卡片本身仍靠边框，阴影只给弹窗、菜单、toast、批量条。
- **绿色当所有主按钮。** `#22C55E` 留给运行、合格、成功。主按钮是蓝，避免「启动」和「确定」变成同一种绿。
- **错误按钮白字。** 白字在 `#EF4444` 上约 3.8:1。技能的 on-destructive 是黑色，实心错误按钮用 `#0F172A` 字（约 4.7:1）。深色底上的错误文字用 `#F87171`（在卡片上约 5.7:1），因为 `#EF4444` 在卡片上只有约 4.2:1。
- **正文 16px。** 技能的通用检查项写 16px。这台控制台沿用现有 13px 正文，配合密度 8；不小于 12px。桌面键鼠控件高 32px，图标按钮 28–32px。44px 触控尺寸不用于这个窗口。
- **浅色作为默认。** 风格条目写 Light not-recommended。默认深色。浅色作为可选主题保留，因为当前原型是浅色，而且任务允许在合适时提供浅色。浅色成功/错误文字改用更深的 `#15803D`、`#DC2626`，保证压在白底上过 4.5:1。

## 6. 配置项交互

快速创建卡片两行，没有「更多设置」，也不填 slot、不选手动代理。

第一行从左到右，控件高 32px，列间距 12px：

| --- | --- | --- |
| 线路 | 88px | 亚洲 / 欧洲 / 美洲。默认美洲 |
| 国家 / 地区 | 124px | 只够放下国旗、最长国名（新加坡）和箭头 |
| 州 / 省 | 200px | 跟着国家走 |

| 创建并启动 | 按文字撑开，高 36px | 主按钮 |

第二行左对齐，与第一行间距 12px：IP 检测开关，旁边是严格 / 宽松；再往后是 IPIP 检测开关。两个开关默认关。IP 检测关掉时，严格 / 宽松置灰且不可点，视觉上仍停在「严格」。打开后可以改，再次关掉会记住上一次的选择。IPIP 检测是独立开关，没有附加选项。这两个检测怎么判定，还没定。

点「创建并启动」时，先按地区前缀生成 N 个 slot，再对每个环境调用 `assignProxy(country, region)` 分配代理，再按内部规则各生成一套指纹并锁定，最后按序号逐个启动。某个启动失败只把那一行标成「异常」，已经生成或已经启动的不受影响。

国旗是本地 SVG，不请求网络。旗帜用它自己的颜色，不进主题令牌。国家、州/省、启动网址、已过期、ASN/ISP 这版用假数据填进效果图，字段本身已经定了。

### 6.1 国家 / 地区、州 / 省

线路默认「美洲」，国家跟着线路变。改线路会把国家重置成该线路的第一项，并清空州/省。

| 线路 | 国家 |
| --- | --- |
| 美洲 | 美国、加拿大 |
| 亚洲 | 新加坡、日本 |
| 欧洲 | 德国、英国 |

国家默认「美国」，带美国国旗。只有美国有州/省：加利福尼亚州（`us-la` / 洛杉矶 / `losangeles`）、纽约州（`us-ny` / `newyork`）、伊利诺伊州（`us-il` / `chicago`）、得克萨斯州（`us-tx` / 达拉斯 / mock 城市 `dallas`）。改国家会清空州/省。美国未选州就提交：「请选择州/省」。加拿大、新加坡、日本、德国、英国没有州/省，这项禁用，说明「该国家无州/省」。语言和时区不跟这个下拉走，它们属于自动生成的指纹。

### 6.2 多开数量

N 表示这一次创建 N 个彼此独立的环境，并逐个启动。每个环境各自随机生成指纹。

默认 1。必须是 1 到 10 的整数。小于 1、大于 10 或不是整数：「多开数量须为 1 到 10 的整数」。10 是建议上限，避免一次拉起过多进程。

slot 名不让人填，一律按地区前缀自动续号。美国 + 加利福尼亚的前缀是 `us-la-slot`。已有 `us-la-slot2`、N = 3 时，生成 `us-la-slot3`、`us-la-slot4`、`us-la-slot5`。序号取该前缀下已有最大数字再加 1，连续取 N 个。若并发导致算出来的名字已存在，整批不创建，toast「该 slot 已存在，请换一个名字」，已有环境不动。

生成阶段全部成功之后才开始启动。按序号一个一个启动。某个失败：该行状态「异常」，操作是「重试」；其余行该运行的运行、该关闭的关闭。重试只再次启动这一行，成功后变成「运行中」。

### 6.3 启动网址（可选）

这 N 个环境共用这一个网址。默认可以空着。空表示不附加。非空必须匹配 `^https?://`，否则：「请输入以 http:// 或 https:// 开头的网址」。效果图里填了假地址 `https://www.example.com`。写入启动命令时的参数名还没定。

### 6.6 指纹

员工不能选，界面上没有分段按钮。创建每个环境时由内部规则随机生成（语言、时区、地理位置、分辨率、字体、ClientRects、WebRTC、Canvas、WebGL、WebGL Info），立刻锁定，不能重新生成。同一批里的 N 个环境各生成各的，互不相同。

查看环境弹窗只读。黄条「人设已锁定，仅查看」。指纹用摘要文字，不用控件，例如：语言 en-US、时区 America/Los_Angeles、屏幕 1920×1080、`Geo:允许 · CR:关 · Canvas:真实 · WebGL:噪声 · GPU:Intel`。下面一句：「由内部规则在创建时随机生成，员工不能修改。」具体随机规则以后再接，本版不在界面里暴露。

### 6.7 外观

系统设置顶部是「外观」，分段按钮「深色 / 浅色」。默认深色。点选后立即切换整窗，选择写在本机，下次打开沿用。两套 token 都在 `tokens.css`（`:root` 与 `[data-theme="light"]`）和 `naive-theme.ts`（`themeOverridesDark`、`themeOverridesLight`）。深色要和 Naive 的 `darkTheme` 一起用；浅色只覆盖 `themeOverridesLight`。

## 10. 已定

- 指纹由创建时的内部规则随机生成并锁定，员工不能选，也不能重新生成。同一批里每个环境各生成一套。
- 没有「更多设置」。快速创建第一行是线路、国家、州/省、多开数量、启动网址。国家下拉宽 124px。第二行是 IP 检测和 IPIP 检测，默认关。
- slot 一律按地区前缀自动续号，创建页不提供输入。
- 代理不在创建时选择。`assignProxy(country, region)` 按国家与州省分配，mock 生成对应城市的示例 URI。验证仍只在代理管理页。
- 查看环境里的指纹是只读摘要文字。
- 时间用浅灰小字放在环境名称下面，不设「最后使用」列。
- 创建成功但启动失败：环境保留，该行「异常」，可重试。不影响同批其他环境。
- 已运行的环境再点「打开」：窗口切到前面。
- 多开数量 N = 一次创建 N 个独立环境并逐个启动。slot 按前缀自动续号。建议上限 10。
- 国家/州省、启动网址、已过期、ASN/ISP、网络状态，本版效果图用假数据。
- 深色和浅色两套皮肤都做，默认深色。系统设置里切换，立即生效，记在本机。
