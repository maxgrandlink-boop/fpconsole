# fpconsole 设计规范

桌面端浏览器实例（环境）管理台。深色为默认外观，信息密度按运营批量操作来排。本文只描述界面与交互，业务规则全部来自当前 `main` 上的原型：`web/mock-notes.md`、`web/app.js`、`web/mock.js`、`web/index.html`。没有写进旧代码的行为，放在文末「待确认」，效果图里若出现，只作为把交互画清楚的界面草案。

实现目标栈是 electron-vite + Vue 3 + TypeScript + Naive UI。令牌映射在 `design/naive-theme.ts`，已按 naive-ui 2.45 的 `GlobalThemeOverrides` 通过类型检查。效果图使用同一套变量：`design/tokens.css`。

## 1. 现有功能清单

原型是纯前端 MOCK：内存数据，刷新重置；路径设置写入 `localStorage`（键 `fpconsole-path-settings`）。右上角 MOCK 徽标点开后 toast：「当前为纯 UI 原型（MOCK 模式）：所有数据为内存 mock，刷新页面即重置」。路由 `#/env`（默认）、`#/proxy`；`#/` 与未知 hash 回落到环境管理。

| --- | --- | --- | --- | --- | --- | --- | --- |
| us-la-slot1 | 默认分组 | 是 | 是 | 2 | 1920×1080 | Chrome/155 | 静态，71.219.34.18，美国-洛杉矶，合格，最后检测 2026-11-13 10:05 |
| us-la-slot2 | 默认分组 | 否 | 否 | 0 | 2560×1440 | Chrome/153 | 直连，98.42.67.11，美国-纽约，不合格，最后检测 2026-11-13 09:30 |

两条时区都是 `America/Los_Angeles`，语言 `en-US`，指纹为下面的默认值。slot2 的分辨率改为 2560×1440。数据里另有 `name`（日常主号 / 备用号），表格「名称」列渲染的是 slot，不渲染 `name`。

### 1.2 新建与锁定

- slot 必填，最长 64。空：弹窗内联「请填写 slot 名」。重复（大小写不敏感）：409，内联 + toast「该 slot 已存在，请换一个名字」。
- 提交中按钮文案「生成中…」并禁用。成功 toast：「环境「{slot}」已生成并锁定」，新行立刻出现：已锁定、used=0、代理未检测、类型静态、smartproxy 随机城市 URI、分组默认分组、不置顶、不星标。
- 语言 = 基于 IP 生成时，记录值为 `en-US`；自定义则用输入，空则回落 `en-US`。
- 时区 = 基于 IP 生成时，记录值为 `America/Los_Angeles`；自定义用下拉值。
- 分辨率 = 随机时，从 `1366×768`、`1440×900`、`1536×864`、`1600×900`、`1920×1080` 里抽一个；快捷选择或自定义都用同一个下拉的值，默认 `1920×1080`。
- 新环境的 Chrome 主版本在 150–156 间随机，不是表单项。
- 警示原文：「生成后永久固定，不可重新生成。指纹一旦生成立即锁定，与该槽位永久绑定；本界面不提供任何「重新生成」入口。」
- 查看（行内编辑图标）打开同一面板的只读态：控件 disabled，黄条「人设已锁定，仅查看」，底部只有「关闭」。没有编辑保存。

### 1.3 列表行为

- 搜索即时过滤，匹配 slot、name、时区、分辨率、UA、IP、地区、分组，大小写不敏感。无结果：「没有符合关键词的环境」。全空：「还没有环境，点击左侧「＋ 新建环境」生成第一个」。
- 排序：序号、创建时间，再次点击反向。置顶行永远在最前。
- 勾选后底部条：「已选 N 项｜批量启动｜批量停止｜取消选择」。批量启动跳过已运行项，toast：「批量启动完成：启动 {n} 个，跳过 {k} 个（已在运行）」。批量停止：「批量停止完成：停止 {n} 个」。失败分别是「批量启动失败：…」「批量停止失败：…」。
- 行启动成功：「已启动（PID {pid}）」，pid 从 12040 递增；used_count +1，累计启动 +1；运行行绿底、左侧绿边、状态灯、按钮变为停止。已在运行：409，toast「该环境已在运行」。其他失败：「启动失败：」+ message。停止成功：「已停止」；失败：「停止失败：」+ message。
- 重新检测约 1.8–2.7 秒，行内骨架，结果在三条判定间轮换（见代理）。失败：「重新检测失败：」+ message。
- 星标即时切换。失败：「操作失败：」+ message。
- 更多菜单：导出配置、删除。导出下载 `{slot}.fpconsole.json`，成功「配置已开始下载」，失败「下载配置失败：…」。删除先 `confirm`：「确定删除「{slot}」？该操作不可恢复（仅 used_count = 0 可删除）。」used>0：409，「该环境已被使用，不可删除」。成功：「已删除「{slot}」」。
- 启动命令弹窗：展示拼装结果；proxy_uri 可改，改完立刻重拼；「示例」填入 smartproxy URI；「复制」成功「已复制到剪贴板」，失败「复制失败，请手动选择复制」。拼装规则以 `web/mock.js` 的 `assembleCommand` 为唯一权威，本规范不重复参数表。含空格的值加英文双引号。
- 分组管理、批量导入、标签管理、筛选、全部分组、通知铃铛：toast「原型演示：该功能未接入」。刷新：重拉列表并 toast「已刷新」。

### 1.4 代理校验

- 输入 `http://user:pass@host:port`。空提交：「请先填写 proxy_uri」。
- 「示例」填入 `http://client-demo_area-us_city-{losangeles|newyork|chicago}_life-120_session-{10位}:demo-pass@proxy.example.com:9000`。
- 验证过程文案循环：「正在检测代理出口质量」，步骤为建立隧道、请求 ipinfo、解析 org/ASN/地理位置、匹配合格规则（美国消费宽带）。
- 轮换结果，与行内重测共用序号：
  1. 76.89.201.14，US，Charter Communications，合格，「美国消费宽带（Charter 家宽段）」，地区显示美国-洛杉矶
  2. 128.199.85.7，SG，Datacamp Limited，不合格，「机房/Hosting 出口，且非美国（新加坡）」，地区显示新加坡
  3. 12.119.84.203，US，AT&T Enterprises，不合格，「AT&T Enterprises 商务线，非消费宽带」，地区显示美国-达拉斯
- 合格与不合格都是检测完成。连接没建立时原型走「验证失败：」+ message，不产生判定徽章。
- 历史最近 20 条。URI 只显示 host:port。空：「暂无检测记录」。加载失败：「历史记录加载失败：」+ message。
- 「ipinfo 直连检测」是浏览器直连 `https://ipinfo.io/json`（12 秒超时），结果标成直连出口。失败：「ipinfo.io 请求失败：」+ message。

## 2. UI/UX Pro Max 的推荐与取舍

技能版本：`ui-ux-pro-max-cli` 2.15.0，装在用户目录，检索脚本在 `~/.cursor/skills/ui-ux-pro-max/scripts/search.py`。技能本身不进仓库。

### 2.1 采用

- **风格：Dark Mode (OLED)。** 产品类型「Developer Tool / IDE」的主风格就是它，和「深色为主」一致。默认深色。
- **配色家族：Developer Tool / IDE，备注 “Code dark + run green”。** 背景 `#0F172A`，卡片 `#1B2336`，文字 `#F8FAFC`，次文字 `#94A3B8`，运行/成功 `#22C55E`，破坏性 `#EF4444`。
- **蓝色作为焦点与主操作。** 产品行的配色焦点写的是 “Dark syntax theme colors + Blue focus”。技能把 Primary 标成 `#1E293B`，那是石板色表面，铺在 `#0F172A` 上对比约 1.2:1，不能当按钮。主按钮使用同一次补检索里浅色方案的行动蓝 `#2563EB`（白字对比 5.17:1），`#1E293B` 改作抬高表面（弹窗、菜单）。
- **密度 8：间距 xs 2 / sm 4 / md 8 / lg 12 / xl 16 / 2xl 24 / 3xl 32（px）。** 运营表用这一档。
- **动效 3：Subtle。** 悬停、焦点 150ms，弹窗 200ms。落地页用的滚动揭示（GSAP scroll reveal）不用于始终可见的桌面窗体。`prefers-reduced-motion: reduce` 时去掉过渡和循环动画。
- **方差 4：均衡，不走不对称。**
- **字体气质：IBM Plex Sans + JetBrains Mono**（设计系统正文/等宽）。中文走系统字体：文泉驿微米黑、苹方、微软雅黑。效果图把拉丁字形放在 `design/fonts/`，不请求 Google Fonts。
- **表单错误：** 字段下方就地说明，并用 `aria-describedby`；提交失败时，表单顶部放可聚焦的错误摘要（`role="alert"`），条目链到字段。保留行内错误。toast 不能单独代替字段错误。
- **焦点：** 2px 环，颜色 `#93C5FD`（在卡片上对比约 8.7:1）。弹窗不把焦点完全盖住。批量操作是下拉，不另做一条挡住表格的浮条。
- **图标：** 线框 SVG，一种风格。旁边有文字时 `aria-hidden`。只有图标的按钮带 `aria-label`（刷新、路径设置、重新检测、更多、星标、通知）。状态不靠颜色单独表达，药丸里有文字。
- **Vue：** 数字用 `v-model.number`，文本用 `v-model.trim`。复杂校验可以交给 VeeValidate，规则仍以第 6 节为准。

### 2.2 未照搬的部分

- **FAQ / Documentation 落地页结构。** 主检索的 pattern 是文档站。本产品是左导航加右栏：上面快速创建，下面环境列表。产品行里对应的是 “Real-Time Monitor + Terminal”，用来支持状态、命令弹窗和等宽标识。
- **技能示例按钮的 12×24 内边距、悬停上移，以及卡片悬停上移。** 那是落地页片段，和密度 8 冲突。按钮高 32px，卡片靠边框分层，不把整张卡片做成可点击。
- **等宽字体做中文标题。** JetBrains Mono 只用于 slot、IP、URI、命令、次数、时间。界面标题用 IBM Plex Sans。
- **纯黑 `#000000` 窗口底。** 风格关键词里有深黑，但开发者工具色板的背景是 `#0F172A`。留出「底 / 侧栏 / 卡片 / 抬高」四层，窗口才分得清。侧栏再用深一档 `#0B1220`。
- **技能边框 `#475569`。** 它在 `#0F172A` 上只有约 2.4:1，不够做输入框边界（非文本对比要 3:1）。控件边框用同色阶的 `#64748B`（在卡片上约 3.3:1）。表格发丝分割线用 `#334155`，分割线不是控件的唯一边界。
- **技能阴影（0.05–0.15 透明度）。** 在深色底上几乎看不见。层级改为 0.45–0.55 透明度，卡片本身仍靠边框，阴影只给弹窗、菜单、toast、批量条。
- **绿色当所有主按钮。** `#22C55E` 留给运行、合格、成功。主按钮是蓝，避免「启动」和「确定」变成同一种绿。
- **错误按钮白字。** 白字在 `#EF4444` 上约 3.8:1。技能的 on-destructive 是黑色，实心错误按钮用 `#0F172A` 字（约 4.7:1）。深色底上的错误文字用 `#F87171`（在卡片上约 5.7:1），因为 `#EF4444` 在卡片上只有约 4.2:1。
- **正文 16px。** 技能的通用检查项写 16px。这台控制台沿用现有 13px 正文，配合密度 8；不小于 12px。桌面键鼠控件高 32px，图标按钮 28–32px。44px 触控尺寸不用于这个窗口。
- **浅色作为默认。** 风格条目写 Light not-recommended。默认深色。浅色作为可选主题保留，因为当前原型是浅色，而且任务允许在合适时提供浅色。浅色成功/错误文字改用更深的 `#15803D`、`#DC2626`，保证压在白底上过 4.5:1。

## 4. 组件

下列状态都要能用键盘到达。`:focus-visible` 使用 2px `--focus` 环，偏移 1px。禁用不用整块 `opacity` 把文字一起淡掉，改用禁用色。

### 4.1 按钮

高 32px，左右 12px，字重 600。图标+文字间距 6px。

| 种类 | 默认 | 悬停 | 按下 | 焦点 | 禁用 |
| --- | --- | --- | --- | --- | --- |
| 主要 | 蓝底白字 | `#1D4ED8` | `#1E40AF` | 2px 焦点环 | 灰底、禁用字、不可点 |
| 次要 | 透明底，`--border` | 边变 `--border-strong`，底 `--surface-muted` | 同悬停 | 焦点环 | 同上 |
| 幽灵 | 无边框 | 浅底 | 浅底 | 焦点环 | 同上 |
| 警告 | 橙软底 + 橙边 + 橙字 | 实心橙、深色字 | 同悬停 | 焦点环 | 同上 |
| 危险 | 透明，红字红边 | 红软底 | 同悬停 | 焦点环 | 同上 |

用法：一个窗格只有一个主要按钮（下一步、确定、验证、关闭）。停止用警告种。删除用危险种，并先 confirm。行内启动是全圆主要按钮，停止是全圆警告按钮。进行中把文字换成「生成中…」「验证中…」「启动中」，按钮禁用，左侧 14px 转圈。

### 4.2 输入框

高 32px，底 `--bg-sunken`，边 `--border`，字 `--text`，占位 `--text-3` 斜体。等宽字段用 JetBrains Mono。

| 状态 | 表现 |
| --- | --- |
| 悬停 | 边 `--border-strong` |
| 焦点 | 边 `--focus`，2px 环 |
| 禁用 / 只读 | 底 `--surface-muted`，边 `--border-subtle`，字 `--text-2`，仍可读 |
| 错误 | 边 `--danger-text`，下方 12px 错误句，`aria-invalid` + `aria-describedby` |

标签在上，12px，`--text-2`。必填星号用 `--danger-text`。说明文字在控件下，12px，`--text-3`。多行 URI 在窄栏里折行（`break-all`），保证 host:port 看得见。

### 4.3 下拉框

外观与输入框相同，右侧人字。展开层：`--surface-raised`、`--shadow-md`、圆角 8px，项高约 32px。悬停项底 `--surface-muted`。当前项文字 `--focus`。禁用与输入框相同。级联的下级在父级未选时禁用，并说明原因。列表要盖过相邻窗格（打开的一侧提高叠放顺序）。

### 4.4 分段按钮

高 28px，连成一组，选中项蓝底白字。悬停未选中项：字与边变蓝。禁用未选中：`--text-2`。只读查看时选中项保持蓝底，让锁定值仍然读得出来。

### 4.5 弹窗

遮罩 `rgba(2, 6, 23, 0.62)`。面板 `--surface-raised`，圆角 12px，宽：查看环境 640px，命令与路径设置沿用宽面板（约 720px），确认框收窄。标题 16px。点击遮罩或 Esc 关闭（与现原型一致）。初始焦点进入面板，Tab 不跑到后面的页面。只读查看底部只有「关闭」。有表单的面板：取消在左，主要动作在右。

### 4.6 表格

表头 12px、`--text-3`、底 `--table-header`，粘在列表滚动区顶部。行底 `--surface`，分割 `--border-subtle`。悬停 `--surface-muted`。运行行：成功软底，左侧 2px 成功色条。空数据用空态，不用空表格。列顺序：勾选、环境名称、系统/浏览器、地区、代理 IP、ASN/ISP、状态、最后使用、操作。

### 4.7 标签与状态

药丸高 22px，内有文字，不单靠颜色。

| 状态 | 外观 | 数据来源 |
| --- | --- | --- |
| 运行中 | 绿字、绿点 | `instances.status === running` |
| 已关闭 | 次文字、灰点 | 没有 running 实例 |
| 启动中 | 信息蓝、点、按钮转圈并禁用 | 点击打开后、结果返回前。原型不保存这个状态 |
| 已过期 | 筛选标签上的一项 | 原型没有这个状态，数量先为 0 |
| 合格 / 不合格 / 未检测 | 绿 / 红 / 灰，带文字 | `proxy.qualified` 为 true / false / null |
| 静态 | 蓝软底 | `proxy.type === 静态` |
| 直连 | 橙软底 | `proxy.type === 直连` |

星标：空心/实心两形，实心 `--star`，按钮有 `aria-pressed`，放在环境名称旁。置顶：名称前的图钉，`title` 为「置顶」。

### 4.8 加载、空、错误

- **加载：** 列表用 3 行骨架（`--surface-muted` 明暗交替）。代理检测用转圈 + 标题 + 当前步骤。按钮进入进行中文案。骨架区域先占住最终高度。
- **空：** 虚线框，居中 13px 说明，并给出下一步（新建，或重试）。搜索无结果与完全没有环境用第 1.3 节的两句原文。
- **错误：** 字段下红字；表单级用 `role="alert"` 摘要。列表失败占住表格位置，标题「环境列表加载失败」，正文使用代码模板 `环境列表加载失败：` + message，按钮「重试」。连接失败与「不合格」分开：前者是红色 alert「验证失败：」+ message，后者是历史表里的不合格药丸。

### 4.9 Toast

顶部居中，面板 `--surface-raised`，左侧 3px 色条：错误 `--danger-text`，成功 `--success`，信息 `--info`（旧版信息 toast 是黄色，这里改成语义信息色）。带图标和文字。3.8 秒淡出，同文案 8 秒去重。`role="status"`。它不替代字段错误。

- **成员管理：** 没有业务。点进去是空态「即将推出」。
- **代理管理：** 旧版代理校验页，URI、示例、验证、ipinfo 直连检测、最近 20 条历史。

## 6. 配置项交互

快速创建一行，从左到右：国家/地区（国旗 + 名称）、州/省、多开数量、启动网址（可选），最右是主按钮「创建并启动」。卡片右上角「更多设置」，展开后是 slot、代理线路和指纹配置；展开时按钮文案改为「收起设置」。

「创建并启动」把旧版的「生成并锁定」和「启动」收成一次点击。顺序仍是先生成、成功后再启动。任一步失败就停，并用原来的 toast。slot 为空时先展开「更多设置」，焦点落在 slot，行内「请填写 slot 名」，不发请求。

国旗是本地 SVG，不请求网络。旗帜用它自己的颜色，不进主题令牌。

### 6.1 国家 / 地区、州 / 省

旧版没有这两个控件。效果图按已有地区做级联，是否落成正式字段见待确认。

- 国家默认「美国」，带美国国旗。选项只有数据里出现过的：美国、新加坡（新加坡国旗）。
- 选美国后州/省必填。选项：加利福尼亚州、纽约州、伊利诺伊州、得克萨斯州。默认加利福尼亚州，对应地区「美国-洛杉矶」、城市 token `losangeles`，和默认时区、slot1 一致。纽约 → `newyork` / 美国-纽约，伊利诺伊 → `chicago` / 美国-芝加哥。得克萨斯对应检测结果里的「美国-达拉斯」，没有城市 token。
- 改国家会清空州/省。美国未选州就提交：「请选择州/省」。
- 选新加坡时州/省禁用，说明「该国家无州/省」。
- 语言、时区若是「基于IP生成」，不跟这个下拉走。mock 仍写成 `en-US` 与 `America/Los_Angeles`。

### 6.2 多开数量

下拉，默认 1。必须是不小于 1 的整数，否则：「多开数量须为不小于 1 的整数」。当前同一环境只能有一个 running 实例，再次打开会 toast「该环境已在运行」，所以下拉里只有 1 可选。大于 1 见待确认。

### 6.3 启动网址（可选）

旧版没有该字段，也没有对应启动参数。默认空，占位「留空则不附加」。空表示不附加。非空必须匹配 `^https?://`，否则：「请输入以 http:// 或 https:// 开头的网址」。是否写入命令，见待确认。

### 6.4 slot 名

放在「更多设置」里，不占快速创建那一行。默认空，占位 `us-la-slot3`。必填，最长 64，去首尾空格，大小写不敏感判重。空：「请填写 slot 名」。重复：「该 slot 已存在，请换一个名字」，同时 toast。字段下说明：「唯一标识，最多 64 个字符，不区分大小写判重。」

### 6.5 代理线路

同样在「更多设置」里。旧版没有线路目录，只有 URI 和类型（静态 / 直连）。预设：

| 预设 | 类型 | 地区 | URI |
| --- | --- | --- | --- |
| 静态 · 美国-洛杉矶 | 静态 | 美国-洛杉矶 | 示例 URI，城市 `losangeles` |
| 静态 · 美国-纽约 | 静态 | 美国-纽约 | 城市 `newyork` |
| 静态 · 美国-芝加哥 | 静态 | 美国-芝加哥 | 城市 `chicago` |
| 直连 · 美国-纽约 | 直连 | 美国-纽约 | 仍保留 URI。slot2 就是直连且带 URI |
| 自定义 URI | 保持当前类型 | 不改写地区 | 可编辑 URI |

默认「静态 · 美国-洛杉矶」。和州/省联动：选了加利福尼亚州就落到洛杉矶这条。URI 空时点验证：「请先填写 proxy_uri」。「示例」走 `exampleProxyUri()`。「验证」走第 1.4 节。直连不清空 URI。

### 6.6 指纹配置

「更多设置」右半是第 1.2 节的全部分段和默认值。自定义语言、自定义时区、允许地理位置、快捷/自定义分辨率、自定义 WebGL Info 才露出附加控件。随机分辨率隐藏下拉。WebGL Info 选真实时隐藏厂商。顶部保留永久锁定警示。查看弹窗里这些控件 disabled，选中项仍是蓝底。

## 7. 环境列表

列表在创建卡片下面。顶部左侧四个筛选标签，各带数量：全部、运行中、已关闭、已过期。右侧：搜索（占位「请输入关键词」）、批量操作下拉、刷新。

筛选只按状态。搜索仍即时匹配 slot、name、时区、分辨率、UA、IP、地区、分组。旧版的分组管理、批量导入、标签管理、全部分组仍是「原型演示：该功能未接入」，没有放进这条工具条。通知铃铛同样。

批量操作下拉里是「批量启动」「批量停止」，文案和跳过规则同第 1.3 节。未勾选时下拉里的两项不可用。

表格列：

| 列 | 内容 |
| --- | --- |
| 勾选 | 行选择，给批量操作用 |
| 环境名称 | slot。置顶图钉、星标仍在 |
| 系统 / 浏览器 | 由 UA 来。预置行是 `Win10 · 155`、`Win10 · 153`（Windows NT 10.0，Chrome 主版本） |
| 地区 | 本地国旗 + 地区。slot1 美国-洛杉矶，slot2 美国-纽约 |
| 代理 IP | 人设上的 IP。没有则「—」 |
| ASN / ISP | 人设记录里没有这一列。效果图写「—」。检测历史里的 org 不回填到另一条 IP |
| 状态 | 圆点 + 文字：运行中、已关闭。启动中只在请求未返回时出现 |
| 最后使用 | 原型没有这个时间。效果图暂用创建时间（slot1 `11-12 10:24`，slot2 `11-13 09:41`） |
| 操作 | 运行中：打开、关闭、更多。未运行且 used_count = 0：打开、删除、更多 |

打开 = 旧版启动。环境已经在运行时，原型 toast「该环境已在运行」。参考图在运行行仍放着「打开」，效果图照这个排布，点下去的结果见待确认。关闭 = 停止。删除沿用 confirm 和第 1.3 节的 409。更多里放：查看指纹、导出配置、启动命令、星标。删除不放进更多，避免和行上的删除重复。

效果图里 slot1 已启动：运行中。slot2 已关闭，used_count 仍是 0，所以操作是删除。使用次数不再单独成列，规则还在：启动成功 +1，大于 0 不能删。

已过期的数量是 0。点开会是空态「没有已过期的环境」。这个状态本身待确认。

## 10. 待确认

1. **国家 / 州省**是否做成正式字段。旧版只有代理结果里的地区，以及 URI 里的 `losangeles` / `newyork` / `chicago`。达拉斯没有城市 token。丹佛、凤凰城只在时区下拉里。
2. **基于 IP 生成**的语言和时区，是否改成跟随出口 IP。现在 mock 写死 `en-US` 与 `America/Los_Angeles`。国家下拉在未确认前不覆盖它们。
3. **启动网址**是否存在，非法时是否用第 6.3 节的文案，以及会不会进入启动命令。
4. **多开数量**和「一个环境一个 running 实例」冲突。大于 1 是禁用、警告，还是真的多开。效果图只有 1。
5. **创建并启动**是否就是先生成再启动。任一步失败是否停在已生成、未启动。
6. 运行中的行上，**打开**是提示「该环境已在运行」，还是把已经打开的窗口带到前面。
7. **已过期**没有数据来源。筛选先显示 0。要不要这个状态，过期规则是什么。
8. **已关闭**用作未运行的标签。旧界面没有这个词。是否就用这四个字替换原来的停止态。
9. **最后使用**没有字段。效果图暂用创建时间。要不要改成最近一次启动或停止时间。
10. **ASN / ISP** 不在人设上。检测历史有 org，但是另一条 IP。这一列留空，还是检测成功后写回该环境。
11. **网络状态**检测的是本机连通、代理，还是别的。异常时除了左下角和一条提示，还有没有别的动作。
12. **成员管理、环境设置** 保持「即将推出」，还是有未写入原型的页面。
13. **系统设置** 只放路径设置，是否还要并入别的项。
14. 分组管理、批量导入、标签管理、通知是否继续只做演示 toast。它们不在新工具条上。
15. 地理位置、字体、分辨率的「自定义」没有额外输入。分辨率的自定义和快捷选择共用一个下拉。
16. 预置 `name`（日常主号 / 备用号）和名称列（slot）不一致。快速创建要不要显示名。
17. 新建时代理城市在 mock 里是随机的，可能和默认州不一致。以表单为准，还是继续随机。
18. 浅色是否做进 Vue 版。默认仍是深色，浅色令牌已备好。
